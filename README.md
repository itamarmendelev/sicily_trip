# אפליקציית הטיול לסיציליה

אתר סטטי (PWA) בלי שלב בנייה. התוכן נטען מקובצי JSON בתיקייה `data/`, והקוד נפרד מהם.

## מבנה
- `index.html`, `css/styles.css`, `js/app.js` – הממשק
- `data/` – נתוני הטיול (מקור המידע של האפליקציה). יומן שינויים ב-`data/CHANGELOG.md`; פריטים שהוסרו נשמרו ב-`data/archive/`
- `sw.js`, `manifest.webmanifest`, `icons/` – התקנה ועבודה ללא אינטרנט

## פרסום ב-GitHub Pages
1. מעלים את כל תוכן התיקייה ל-repo (כולל `.nojekyll`).
2. Settings ← Pages ← Deploy from a branch ← הענף `main` והתיקייה `/ (root)`.
3. הכתובת תהיה `https://<משתמש>.github.io/<repo>/`. פותחים בטלפון ומוסיפים למסך הבית.
שימו לב: ב-repo ציבורי הנתונים (שמות, טלפונים, דוא״ל) גלויים לכל מי שיש לו את הקישור.

## עדכון נתונים
מחליפים קובץ בתיקיית `data/` (Add file ← Upload files) ושומרים (Commit). אחרי דקה-שתיים האתר מתעדכן. בפתיחה הבאה עם אינטרנט תוצג ההודעה “התוכן עודכן לגרסה חדשה”. כדאי לערוך בעורך טקסט רגיל, כי פסיק או מרכאה חסרים שוברים את הקובץ. אם קובץ שבור, האפליקציה מציגה הודעת שגיאה עם שם הקובץ.

## עדכון קוד
אחרי שינוי ב-`index.html`, `css/` או `js/` יש להעלות את `sw.js` עם מספר גרסה חדש בשורה הראשונה (כרגע `sicily-v3`, הבא `sicily-v4`). בלי זה מכשירים עם הגרסה הישנה לא יקבלו את הקוד החדש.

## בדיקה מקומית
בתיקייה: `python -m http.server 8000` ואז `http://localhost:8000`. פתיחה ישירה של `index.html` מהקבצים לא תעבוד.
לבדיקת תצוגת יום מסוים מוסיפים לכתובת `?date=2026-12-14`.

## עדיין לא כלול
מפה, תחבורה, מדריך הטיול, משימות, מועדפים והערות אישיות.
